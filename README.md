# IE_Web — สื่อการสอนแบบโต้ตอบ วิชา 010243302 อิเล็กทรอนิกส์อุตสาหกรรม (Industrial Electronics)

เว็บไซต์การเรียนแบบโต้ตอบสำหรับนักศึกษาปริญญาตรี ภาควิชาวิศวกรรมการผลิตและหุ่นยนต์ มจพ.
ตำรา **Boylestad & Nashelsky, Electronic Devices and Circuit Theory, 11th ed.** และสไลด์ประกอบการสอนใน `../Slide/`
รูปแบบเดียวกับ `Claude/Electrical_circuit_for_RE/EE_Web/` (แผนที่การเรียน + หน้าโต้ตอบ + ความคืบหน้าในเบราว์เซอร์ + สองภาษา)
จุดเด่น: **ทุกวงจรถูกแก้สมการจริงในเบราว์เซอร์ ไดโอดใช้เส้นโค้งเดียวกับรูปในตำรา ทรานซิสเตอร์ (BJT, JFET, MOSFET) และออปแอมป์ใช้แบบจำลองของบทเรียน** แล้ววาดกระแสเป็นจุดที่วิ่งตามสายไฟ

สร้างเมื่อ 7 ต.ค. 2569 · **บทที่ 1 ไดโอดสารกึ่งตัวนำ** (6 หน้า) · **บทที่ 2 การใช้งานไดโอด** (9 หน้า) · **บทที่ 3 ทรานซิสเตอร์แบบรอยต่อคู่** (4 หน้า, 8 ต.ค. 2569) · **บทที่ 4 การไบแอสกระแสตรงของ BJT** (7 หน้า, 10 ต.ค. 2569) · **บทที่ 5 ทรานซิสเตอร์สนามไฟฟ้า (JFET)** (5 หน้า, 10 ต.ค. 2569) · **บทที่ 6 มอสเฟต** (4 หน้า, 10 ต.ค. 2569) · **บทที่ 7 ออปแอมป์** (5 หน้า, 10 ต.ค. 2569) · **บทที่ 8 ไอซีเชิงเส้น-ดิจิทัล** (4 หน้า, 11 ต.ค. 2569) · ครบทุกบทของสไลด์แล้ว · **บทเสริม A–B การวิเคราะห์สัญญาณ ac ของ BJT และ FET** (8 หน้า จากตำราบทที่ 5 และ 8 เพราะสไลด์ไม่มี, 11 ต.ค. 2569)

## รูปแบบของหน้า (เล่าเรื่องด้วยสไลด์, 11–12 ต.ค. 2569)

บทนำแบบเกริ่นเรื่อง (คำถามหรือการใช้งานจริง แล้วบอกว่าหน้านี้พาไปไหน พร้อมเลขหน้าสไลด์และหัวข้อตำรา) → กรอบสมการ → ประเด็นสำคัญ → สารบัญ → **เรื่องเล่า** สลับกับส่วนสาธิตและโจทย์: "ตอนที่ 1, 2, …" แต่ละตอนเป็นกล่อง `.story` (หัวข้อย่อย ข้อความ 2–4 ประโยค สไลด์ 1–4 หน้า หมายเหตุสไลด์หรือตำราของสไลด์เหล่านั้น และลูกศร "↓ ส่วน A: …" ชี้ไปยังสิ่งที่จะได้ลองทำต่อ) วางไว้หน้าส่วนสาธิต (ภาพจำลอง + แผงควบคุม + คำอธิบายที่เปลี่ยนตามค่า) หรือโจทย์ (โจทย์ ลองตอบก่อน ภาพจำลองที่เปลี่ยนตามขั้น เฉลยทีละขั้นด้วยปุ่ม) ที่ตอนนั้นนำเข้าไป และกล่อง `.story.in` (ไม่มีหัวข้อ 1–3 ประโยค) ใต้หัวข้อของโจทย์สำหรับสไลด์ของโจทย์นั้น → ฝึกเพิ่ม → ลองทำดู
- ไม่มีแกลเลอรีรวมสไลด์อีกแล้ว (ผู้สอนไม่ต้องการให้สไลด์มารวมกันที่เดียว) สไลด์แต่ละหน้าอยู่ ณ จุดที่ใช้ความคิดนั้นครั้งเดียว แตะเพื่อขยาย บางหน้าเรียงส่วนใหม่ตามเรื่อง (เช่น 7.1, 8.2, 8.3)
- เขียนเรื่องจากเนื้อหาที่ตรวจแล้วของหน้า (คำอธิบายสไลด์ โจทย์ ประเด็นสำคัญ หมายเหตุ) ไม่เพิ่มตัวเลขใหม่ ภาษาไทยเขียนตัวย่อเต็มครั้งแรก ภาษาอังกฤษไม่มีอักษรไทย
- สร้างด้วยสคริปต์ storify (ข้อกำหนดต่อหน้า → ย้ายสไลด์เข้ากล่องเรื่องเล่า ตรวจว่าไม่มีสไลด์หายหรือซ้ำ) และตรวจซ้ำกับเวอร์ชันใน git ว่าชุดสไลด์ สคริปต์ของหน้า และเนื้อในของทุกส่วนไม่เปลี่ยน หลังสร้างแล้วกล่องเรื่องเล่าเป็น HTML ธรรมดา แก้ในหน้าได้ตรง ๆ (CSS: `.story*` ใน `ee.css`)
- สมการจัดตรงเครื่องหมาย = และใส่กรอบคำตอบ ภาษาอังกฤษไม่มีอักษรไทย ตัวย่อเขียนเต็มครั้งแรก
- มิเตอร์วัด V/A ในวงจรซ่อนในโจทย์จนกว่าจะเปิดเฉลย (จาก EE_Web)
- กล่องความเห็นท้ายหน้า (shell.js `FEEDBACK`) ยังปิดอยู่: `FEEDBACK.form` ว่าง จนกว่าจะสร้างแบบฟอร์มของวิชานี้ (บนเครื่องตัวเองยังเห็นเป็นตัวอย่าง)

## ไดโอดในตัวแก้วงจร (`circuit.js`, part type `D`)

- `model: 'shockley'` (ค่าเริ่มต้น): สมการ (1.2) `Is`, `n`, `T` (°C) · `vz` ทำให้พังทลายที่ −vz (`ibv` A ที่ −vz) · `zsym: false` วาดสัญลักษณ์ไดโอดธรรมดาแม้มี `vz`
- `'table'`: `curve: [[V, A], …]` จาก 0 V ขึ้นไป (pchip ของ Fritsch–Carlson) และ `Irev` (A) ด้านไบแอสกลับ
- `'ideal'`, `'simple'` (`vk`), `'pwl'` (`vk`, `r`) · `led: true` วาดลูกศรแสงและแสงเรือง (`ledColor`, `ledFull`)
- แก้ด้วย Newton–Raphson ครอบการแก้ MNA เดิม (`solve1`): จำกัดก้าวแบบ SPICE (pnjlim) สำหรับเอกซ์โพเนนเชียล ก้าวละไม่เกิน 0.25 V สำหรับตาราง และหน่วงก้าวของแบบเส้นตรงหลัง 60 รอบ ใช้ได้ทั้งกระแสตรงและการจำลองตามเวลา (กระแสสลับใช้ความชันที่จุดกระแสตรงล่าสุด)
- \(V_T\) ใช้ค่าคงที่ของตำรา k = 1.38e-23, q = 1.6e-19, T_K = 273 + °C → 25.875 mV ที่ 27 °C (Example 1.1)
- แบบเส้นตรงขณะไม่นำ: ไบแอสกลับเป็นเปิดวงจรพอดี ส่วนไบแอสตรงที่ยังไม่ถึงเข่ามีกระแสรั่ว `GFWD` = 0.1 µS (≤ 0.07 µA ที่ 0.7 V) และไดโอดที่ค้าง "นำ" โดยแทบไม่มีกระแสจะถูกเริ่มใหม่จาก "ไม่นำ" หนึ่งครั้ง ไดโอดสองตัวอนุกรมที่หันสวนกันจึงได้ตามตำรา (I = 0 ⇒ V_D = 0 ตัวที่หันสวนรับแรงดันทั้งหมด)
- แหล่งจ่าย `V` มี `wave: 'sine' | 'square' | 'tri'` (วาดรูปคลื่นในวงกลม หน้าเว็บกำหนดค่าเองทุกเฟรมหรือใช้ `fn(t)`) · โหมด `'tran'` แก้ครั้งแรกด้วยก้าว 1 µs ถ้าไม่ได้ส่ง dt · `CK.badge` วาด `X_sub` เป็นตัวห้อย

## ทรานซิสเตอร์ในตัวแก้วงจร (`circuit.js`, part type `Q`, 8 ต.ค. 2569)

- ขา `C`, `B`, `E` (ชื่อโหนด; วาด C กับ E บนเส้นเดียวกัน แนวตั้งหรือแนวนอน ขาเบสอยู่ด้านข้างระดับกึ่งกลางสัญลักษณ์) · `pnp: true` · `pins: true` เขียน C, B, E ข้างขา · ผลลัพธ์ `I[id]` = I<sub>C</sub> (C → E), `I[id + ':b']` = I<sub>B</sub> (B → E), `circuit.Q(id)` = { IB, IC, IE, VBE, VCE, VCB, region } ในรูปของ npn (pnp: ขนาดเป็นบวกเมื่อนำ)
- กระแสเบสเป็นไดโอดจากเบสไปอิมิตเตอร์ `be` (แบบใดก็ได้ของ `D`; ค่าเริ่มต้น `{ model: 'simple', vk: 0.7 }` คือ V<sub>BE</sub> = 0.7 V เมื่อนำ) หรือรายการ `[{ vce, …diode }]` ของลักษณะสมบัติด้านเข้าที่ V<sub>CE</sub> หลายค่า (เส้นตรงระหว่างกัน)
- กระแสคอลเล็กเตอร์ (แบบ CE, ค่าเริ่มต้น): I<sub>C</sub> = (β I<sub>B</sub> + `iceo`)·S(v<sub>CE</sub>)·(1 + v<sub>CE</sub>/`va`) โดย S(v) = 1 − e<sup>−(v − `vsat`)/0.02</sup> (ย่านอิ่มตัว; `vsat` = 0 ตาม V<sub>CE(sat)</sub> ≅ 0 ของบทที่ 4) · `fam` = ชุดเส้นด้านออกที่อ่านจากรูป (`CK.BJT.family`, เส้นตรงระหว่างเส้น I<sub>B</sub>) · `alpha` (แบบ CB): `be` ให้ I<sub>E</sub>, I<sub>C</sub> = (α I<sub>E</sub> + `icbo`)·S — ใช้กับรูป 3.7 เพราะในย่านอิ่มตัวแบบ CE ต้องการ I<sub>B</sub> สูงจน v<sub>BE</sub> จากตารางพุ่งเกินจริง (Newton ไม่ลู่เข้า) แบบ CB ให้อิมิตเตอร์คงกระแสไว้
- Newton–Raphson บน (v<sub>BE</sub>, v<sub>CE</sub>) พร้อมไดโอดในลูปเดียวกัน: กระแสทั้งสองถูกทำเป็นเชิงเส้นด้วยความชันสี่ค่า (`stampG` คือ transconductance ระหว่างโหนดใด ๆ) จำกัดก้าว v<sub>BE</sub> ตามแบบของ `be` และหน่วงทั้งคู่หลัง 60 รอบ · กวาด 527 + 2244 กรณี (หน้า 3.3 และ 3.2) ลู่เข้าภายใน 12 รอบ · 11 ต.ค. 2569 (แบบจำลอง β): v<sub>BE</sub> ไม่เกินเข่า + 0.1 V, v<sub>CE</sub> ลดได้ไม่เกินสี่เท่าต่อรอบและไม่ติดลบ, เกณฑ์ลู่เข้าของ v<sub>CE</sub> 1 µV (เดิมวงจรตัวแบ่งแรงดันที่ R<sub>2</sub> ใหญ่วิ่งไปที่ V<sub>CE</sub> = −36.8 V) ทดสอบ 84 วงจรสุ่มรวมถึงอิ่มตัว
- ย่าน: `cutoff` เมื่อ I<sub>B</sub> < 0.1 µA, `saturation` เมื่อ v<sub>CE</sub> < `satAt` (ค่าเริ่มต้น vsat + 0.08 V; ชุดเส้นจากรูปใช้ 0.3 V หรือ 0.7 V) · ตัวช่วย `CK.BJT.icAt`, `vbeAt`, `cb(p, I_E, V_CB)` สำหรับวาดลักษณะสมบัติจากแบบจำลองเดียวกับวงจร
- สัญลักษณ์มีวงกลมจาง ลูกศรอิมิตเตอร์ (npn ชี้ออก pnp ชี้เข้า) วาดซ้ำทับจุดกระแส จุดกระแส I<sub>C</sub> วิ่งเข้าคอลเล็กเตอร์ผ่านแผ่นเบสออกอิมิตเตอร์ และ I<sub>B</sub> จากขาเบสสมทบที่อิมิตเตอร์ · ชี้เมาส์ที่ทรานซิสเตอร์เห็นย่าน I<sub>B</sub>, I<sub>C</sub>, I<sub>E</sub>, V<sub>BE</sub>, V<sub>CE</sub> · มิเตอร์วัด V/A หนีบที่ทางคอลเล็กเตอร์ได้ I<sub>C</sub>

## FET ในตัวแก้วงจร (`circuit.js`, part type `J`, 10 ต.ค. 2569)

- ขา `D`, `G`, `S` (ชื่อโหนด; D กับ S บนเส้นเดียวกัน เกตด้านข้างระดับกึ่งกลาง) · `pch: true` p-channel (ทุกอย่างในรูปของ n-channel: v<sub>SG</sub>, v<sub>SD</sub> และกระแสกลับทิศ) · `pins: true` เขียน D, G, S · ผลลัพธ์ `I[id]` = I<sub>D</sub> (D → S), `I[id + ':g']` = I<sub>G</sub> (G → S), `circuit.J(id)` = { ID, IG, IS, VGS, VDS, VDG, region, vov, rd }
- แบบจำลอง (`CK.FET`, กฎกำลังสองของสมการของ Shockley): ย่านอิ่มตัว (v<sub>DS</sub> ≥ v<sub>GS</sub> − V<sub>P</sub>) I<sub>D</sub> = I<sub>DSS</sub>(1 − v<sub>GS</sub>/V<sub>P</sub>)² (× (1 + (v<sub>DS</sub> − v<sub>GS</sub> + V<sub>P</sub>)/`va`) ถ้าให้ `va`) · ย่านโอห์มิก (0 ≤ v<sub>DS</sub> < v<sub>GS</sub> − V<sub>P</sub>) I<sub>D</sub> = I<sub>DSS</sub>/V<sub>P</sub>² · [2(v<sub>GS</sub> − V<sub>P</sub>)v<sub>DS</sub> − v<sub>DS</sub>²] ต่อเนื่องและความชันต่อเนื่องที่แนวพินช์ออฟ · คัตออฟเมื่อ v<sub>GS</sub> ≤ V<sub>P</sub> · ความต้านทานที่จุดกำเนิด r<sub>d</sub> = r<sub>o</sub>/(1 − v<sub>GS</sub>/V<sub>P</sub>) ยกกำลังหนึ่ง (สมการ 6.1 ของตำรายกกำลังสอง เป็น "ค่าประมาณขั้นแรก"; หน้า 5.1 ข้อ 2 แจ้งไว้) · `kind: 'jfet'` (ค่าเริ่มต้น; `idss`, `vp` < 0; ไดโอดเกต `gate` จาก G ไป S ค่าเริ่มต้น 0.7 V, `gate: false` ปิด), `'dmos'` (สมการเดิมทั้งสองข้างของ v<sub>GS</sub> = 0 ไม่มีไดโอดเกต), `'emos'` (I<sub>D</sub> = `k`(v<sub>GS</sub> − `vt`)²) · `CK.FET.biasOf(p, R, V_G)` จุดตัดของเส้น v<sub>GS</sub> = V<sub>G</sub> − I<sub>D</sub>R กับเส้นโค้งของอุปกรณ์ทุกชนิด (10 ต.ค. 2569)
- Newton–Raphson บน (v<sub>GS</sub>, v<sub>DS</sub>) ในลูปเดียวกับไดโอดและ BJT (กฎกำลังสองเรียบ จึงใช้ Newton ธรรมดา หน่วงหลัง 60 รอบ) · ลู่เข้าภายใน 3–10 รอบในทุกวงจรของบท · ตัวช่วย `CK.FET.id` (สมการ 6.3), `vgs` (สมการ 6.8), `bias(idss, vp, R_S, V_G)` จุดตัดของเส้น V<sub>GS</sub> = V<sub>G</sub> − I<sub>D</sub>R<sub>S</sub> กับเส้นโค้ง (แบ่งครึ่ง), `iv` กระแสกับความชัน g<sub>m</sub>, g<sub>ds</sub> และย่าน
- สัญลักษณ์ตามรูป 6.14: แท่งช่องหันเข้าหาเกต ขาเดรนและซอร์สต่อปลายแท่งผ่านขาสั้น ขาเกตเข้ากลางแท่งพร้อมลูกศร (n-channel ชี้เข้า p-channel ชี้ออก) วาดซ้ำทับจุดกระแส · `kind: 'dmos' | 'emos'` วาดเป็น MOSFET ตามรูป 6.30/6.39: แผ่นเกตฉนวนขนานกับแท่ง แท่งทึบ (ดีพลีชัน) หรือขาดสามท่อน (เอนแฮนซ์เมนต์) และเส้นสารฐานจากกลางแท่งไปขาซอร์สพร้อมลูกศร · จุดกระแส I<sub>D</sub> วิ่งเข้าเดรน ลงตามแท่ง ออกซอร์ส · ชี้เมาส์เห็นย่าน (คัตออฟ / โอห์มิก / อิ่มตัว) I<sub>D</sub>, I<sub>G</sub>, V<sub>GS</sub>, V<sub>DS</sub> (p-channel แสดงเครื่องหมายตามตำรา) · มิเตอร์จิ้มที่เกตได้
- ก้าวของ Newton มีขอบเขต (11 ต.ค. 2569, แบบ fetlim ของ SPICE): v<sub>GS</sub> ของ JFET ไม่เกินเข่าของรอยต่อเกต + 0.1 V และหลังสองรอบแรก v<sub>GS</sub> เปลี่ยนได้ไม่เกิน max(0.5, 0.35|V<sub>P</sub>|) V ต่อรอบ v<sub>DS</sub> ไม่เกิน 4 V · ก่อนแก้ วงจรตัวแบ่งแรงดันที่ V<sub>P</sub> = −3 V บางชุดสลับระหว่างคัตออฟกับนำเต็มที่จนครบ 400 รอบ · `tests.html` กวาด 144 วงจร (ไบแอสตัวเอง/ตัวแบ่งแรงดัน, V<sub>P</sub> −3 ถึง −8 V และดีพลีชันมอสเฟต) ทุกวงจรลู่เข้าภายใน 60 รอบและตรงกับสมการของ Shockley กับวงรอบเกต (รวมกระแสเกตรั่วระดับ nA เมื่อเกตถูกดันเป็นบวกเล็กน้อย)
- ข้อค้นพบจากการแก้วงจรจริง: จุด Q ของ Example 7.1 (V<sub>DS</sub> = 4.75 V < V<sub>GS</sub> − V<sub>P</sub> = 6 V) และของ Example 7.3(a) (R<sub>S</sub> = 100 Ω: เส้นโค้งบอก 6.4 mA แต่ V<sub>DD</sub> − I<sub>D</sub>(R<sub>S</sub> + R<sub>D</sub>) ติดลบ) อยู่ในย่านโอห์มิก ตำราใช้สมการของ Shockley โดยไม่ตรวจ หน้าเว็บเฉลยตามตำราแล้วแจ้งค่าจริงของภาพจำลอง (5.48 mA, 5.04 V และ 5.07 mA, 2.78 V)

## บทเสริม ac ของ BJT และ FET (`ie9.js`, 11 ต.ค. 2569)

ผู้สอนขอเนื้อหาการวิเคราะห์สัญญาณ ac ของทรานซิสเตอร์และ FET ซึ่งสไลด์ไม่มี จึงสร้างจากตำราบทที่ 5 (BJT AC Analysis) และบทที่ 8 (FET Amplifiers) เป็นขั้นที่ 6 ของแผนที่ ("บทเสริม", สีม่วง, หน้า A.1–A.4 และ B.1–B.4) รูปแบบเดียวกับหน้าอื่น (เรื่องเล่า ส่วนทดลอง โจทย์เปิดเฉลยทีละขั้น ลองตอบก่อน ฝึกเพิ่ม ลองทำดู)
- **วงจรจริง ไม่ใช่วงจรสมมูล**: ตัวแก้วงจรแก้วงจรขยายทั้งวง (ตัวเก็บประจุ แหล่งจ่าย ทรานซิสเตอร์) โหมด `ac` ใช้ธงใหม่ `dcFirst` (หาจุดทำงานแบบ dc โดยปิดแหล่ง ac ก่อน แล้วทำทรานซิสเตอร์เป็นเชิงเส้นที่จุดนั้น) ความถี่ 100 kHz ซึ่งตัวเก็บประจุทุกตัวของตัวอย่างเป็นลัดวงจร (ทรานซิสเตอร์ไม่มีความจุภายใน = แบบจำลองย่านกลางของตำรา)
- **ตั้งแบบจำลองให้เท่าตำรา** (`AC.tune`): BJT ใช้รอยต่อ Shockley ที่ V<sub>T</sub> = 26 mV·β/(β + 1) (วงจรอิมิตเตอร์ร่วม) หรือ 26 mV (เบสร่วม ตัวตามแรงดัน) แล้วเลือก I<sub>s</sub> ให้ V<sub>BE</sub> = 0.7 V ที่ I<sub>B</sub> จริง ผลคือแบบจำลองไฮบริด-π ของตัวแก้วงจร **เท่ากับแบบจำลอง r<sub>e</sub> ของตำราทุกประการ** (Z<sub>b</sub> = βr<sub>e</sub>, βI<sub>b</sub> = v<sub>be</sub>/r<sub>e</sub>) r<sub>o</sub> มาจากแรงดัน Early โดยหาร β ด้วย (1 + V<sub>CE</sub>/V<sub>A</sub>) ให้ I<sub>C</sub> = βI<sub>B</sub> คงเดิม · FET ใช้ `lam` ใหม่ใน `circuit.js` (I<sub>D</sub>(1 + λv<sub>DS</sub>) แบบ SPICE) λ = 1/(r<sub>d</sub>I<sub>D</sub> − V<sub>DS</sub>) และหาร I<sub>DSS</sub> (หรือ k) ด้วย (1 + λV<sub>DS</sub>) ให้ g<sub>m</sub> ตรงตำรา
- **ทุกโจทย์มีตาราง "มือ | ภาพจำลอง"** ที่เติมตามขั้นที่เปิด ภาพวงจรจริง (จุดคือกระแส dc) แล้วเปลี่ยนเป็นวงจรสมมูล ac ตั้งแต่ขั้นที่วาดมัน ออสซิลโลสโคปสองช่องของ v<sub>i</sub>, v<sub>o</sub> (ขาออกที่ไม่กลับเฟสถูกเลื่อนลงสองช่องให้เห็นทั้งสองเส้น)
- `tests.html` 17 ข้อ: คำตอบของตัวแก้วงจรเทียบสูตรของตำราที่จุดทำงานของมันเอง (ต่างกันไม่ถึง 0.3 %) และตัวอย่างที่คำนวณใหม่แบบละเอียด (5.9, 5.15, 8.11, 8.12, 8.16)
- **ป้ายในวงจรไม่ทับกัน** (11 ต.ค. 2569): `AC.fitLabels` เขียนค่าของตัวต้านทานเฉพาะเมื่อมีที่ก่อนชิ้นถัดไป (ฟังก์ชัน `valText(p, view)`; `circuit.js` ส่ง view ให้แล้ว) บนโทรศัพท์วงจรสมมูลจึงเหลือแต่ชื่อ · C<sub>1</sub>, C<sub>2</sub> เขียนชื่อซ้อนบนค่า (`stack`) · ตัวต้านทานไบแอสตัวบนหยุดก่อนเส้นเบส · ตรวจด้วยตัวตรวจป้ายในหน้า tests (บันทึกการวาดข้อความ เส้น และวงกลมของแต่ละวงจร แล้วหาข้อความทับข้อความ/ทับเส้น) ทั้ง 8 หน้า ทุกโจทย์ที่ขั้น 0, 3 และขั้นสุดท้าย ที่ 1100 และ 375 px: ไม่พบ
- ข้อผิดพลาดของตำรา: แก้แล้วในหน้าเว็บทุกจุด (เฉลยใช้ค่าที่ถูก ค่าที่ตำราพิมพ์อยู่ในหมายเหตุและกล่องท้ายหน้า) ดูหัวข้อ "บทเสริม" ในรายการข้อผิดพลาดด้านล่าง

## กล่องความเห็น (Google Forms)

1. เปิด https://script.google.com → New project → วางโค้ดจาก `feedback/create_form.gs` → เลือกฟังก์ชัน `createIeWebFeedbackForm` → Run (อนุญาตสิทธิ์ครั้งแรก)
2. ส่ง FORM_URL, PREFILL, EDIT_URL, SHEET_URL จาก Execution log มาเพื่อใส่ใน `assets/shell.js` (`FEEDBACK.form` และ `entries`)
3. สรุปคำตอบ: ดาวน์โหลดชีตเป็น CSV แล้ว `python3 feedback/summarize.py responses.csv`
