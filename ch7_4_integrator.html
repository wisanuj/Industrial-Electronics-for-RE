The integrator and the differentiator A capacitor in place of a resistor turns the summer into calculus

เปิดก๊อกน้ำค้างไว้ ระดับน้ำในถังคือผลรวมของน้ำทั้งหมดที่ไหลเข้ามาตั้งแต่ต้น ตัวเก็บประจุทำแบบเดียวกันกับประจุ: แรงดันของมันคือผลรวมของกระแสที่ไหลเข้า ใส่ตัวเก็บประจุในตำแหน่งของ \(R_f\) แล้วออปแอมป์จะกลายเป็นอินทิเกรเตอร์ (integrator) ที่บวกสะสมขาเข้าไปตามเวลา สลับตำแหน่ง R กับ C จะได้ดิฟเฟอเรนชิเอเตอร์ (differentiator) ที่บอกว่าขาเข้าเปลี่ยนเร็วแค่ไหน ภาพจำลองทุกภาพในหน้านี้เดินตามเวลาจริง (สไลด์บทที่ 7 ชุดที่ 2 หน้า 3–6 · Boylestad หัวข้อ 10.5)

Leave a tap running and the water level in the bucket is the total of everything that has flowed in since the start. A capacitor does the same with charge: its voltage is the total of the current that has flowed into it. Put a capacitor where \(R_f\) was and the op-amp becomes an integrator that keeps adding up its input over time; swap R and C and it becomes a differentiator that tells how fast the input changes. Every simulation on this page runs in real time steps (chapter 7 slides, set 2, pp. 3–6; Boylestad section 10.5).

$$ v_o(t) = -\frac{1}{RC}\int v_1(t)\,dt $$ $$ v_o(t) = -\left[\frac{1}{R_1C}\int v_1\,dt + \frac{1}{R_2C}\int v_2\,dt + \frac{1}{R_3C}\int v_3\,dt\right] $$ $$ v_o(t) = -RC\frac{dv_1(t)}{dt} $$

ประเด็นสำคัญของหน้านี้

  • อินทิเกรเตอร์ (หน้า 3–4, รูป 10.38): กราวด์เสมือนทำให้กระแสผ่าน R เป็น \(v_1/R\) และต้องไหลเข้า C ทั้งหมด \(v_C\) จึงเพิ่มตามอินทิกรัลของ \(v_1\) ปลายซ้ายของ C อยู่ที่ 0 ขาออกคือ \(-v_C\): \(v_o = -\frac{1}{RC}\int v_1\,dt\) (สมการ 10.12–10.13 ในรูป \(V_o/V_1 = -1/sCR\))
  • ขั้นคงที่ให้ลาดตรง (หน้า 5, รูป 10.39): \(v_1\) = 1 V กับ 1 MΩ, 1 µF ให้ตัวคูณสเกล −1/RC = −1 V/s ขาออกลาดลง −1 V ทุกวินาที R = 100 kΩ ให้ −10 V/s · ขาออกลาดได้จนถึง \(-V_{sat}\) แล้วค้าง: อินทิเกรเตอร์จริงอิ่มตัวเสมอเมื่อขาเข้ามีองค์ประกอบกระแสตรง
  • หลายขาเข้า (รูป 10.40, สมการ 10.14): แต่ละขามีตัวคูณสเกล \(1/R_kC\) ของตัวเอง (200 kΩ, 100 kΩ, 1 MΩ กับ 1 µF ให้ 5, 10, 1) คือวงจรรวมสัญญาณที่เป็นอินทิเกรเตอร์ด้วย: หัวใจของคอมพิวเตอร์แอนะล็อก
  • ดิฟเฟอเรนชิเอเตอร์ (หน้า 6, รูป 10.41): \(i = C\,dv_1/dt\) ผ่าน R ให้ \(v_o = -RC\,dv_1/dt\) คลื่นสามเหลี่ยมให้คลื่นสี่เหลี่ยม คลื่นไซน์ให้โคไซน์ (นำหน้า 90°) ขั้นให้พัลส์แหลมชนราง · ใช้น้อยกว่าเพราะขยายสัญญาณรบกวนความถี่สูง
  • ค่าคงตัวเวลา RC คือตัวเลขเดียวที่กำหนดสเกล: อินทิเกรเตอร์หาร ดิฟเฟอเรนชิเอเตอร์คูณ

Key points of this page

  • The integrator (pp. 3–4, Fig. 10.38): the virtual ground makes the current through R equal to \(v_1/R\), and all of it must flow into C, so \(v_C\) grows as the integral of \(v_1\). The left end of C is at 0, so the output is \(-v_C\): \(v_o = -\frac{1}{RC}\int v_1\,dt\) (Eqs. 10.12–10.13, written as \(V_o/V_1 = -1/sCR\)).
  • A constant step gives a straight ramp (p. 5, Fig. 10.39): \(v_1\) = 1 V with 1 MΩ and 1 µF gives a scale factor −1/RC = −1 V/s, so the output falls 1 V every second; R = 100 kΩ gives −10 V/s. The ramp can only go to \(-V_{sat}\), where it stops: a real integrator always saturates if the input has a dc component.
  • Several inputs (Fig. 10.40, Eq. 10.14): each has its own scale factor \(1/R_kC\) (200 kΩ, 100 kΩ, 1 MΩ with 1 µF give 5, 10, 1): a summing amplifier that integrates too, the heart of the analogue computer.
  • The differentiator (p. 6, Fig. 10.41): \(i = C\,dv_1/dt\) through R gives \(v_o = -RC\,dv_1/dt\). A triangle gives a square wave, a sine a cosine (90° ahead), a step a spike to the rail. Less used, because it amplifies high-frequency noise.
  • The time constant RC is the single number that sets the scale: the integrator divides by it, the differentiator multiplies.

สไลด์หน้า 3 ใส่ตัวเก็บประจุในเส้นป้อนกลับ ขั้ว − ยังเป็นกราวด์เสมือน กระแส \(V_1/R\) จึงไหลเข้า R แล้วต้องไปชาร์จตัวเก็บประจุทั้งหมด เพราะขาเข้าของออปแอมป์ไม่รับกระแส

Slide p. 3 puts a capacitor in the feedback path. The − input is still a virtual ground, so the current \(V_1/R\) flowing in through R must all go on to charge the capacitor, since the op-amp input takes none.

Slide p. 4 solves for \(V_o/V_1 = -1/sCR\) and turns it back into time: \(v_o(t) = -\dfrac{1}{RC}\displaystyle\int v_1(t)\,dt\). The output is the running total of the input, inverted and scaled by \(1/RC\).

ดิฟเฟอเรนชิเอเตอร์: ขาออกบอกความเร็วของการเปลี่ยนแปลง

The differentiator: an output that measures how fast things change

สลับตำแหน่งให้ C อยู่ขาเข้าและ R อยู่เส้นป้อนกลับ (สไลด์หน้า 6) กระแสที่ผ่าน C แปรตามความเร็วที่แรงดันขาเข้าเปลี่ยน จึงได้ \(v_o(t) = -RC\,\dfrac{dv_1(t)}{dt}\)

สไลด์บอกตรง ๆ ว่ามันมีประโยชน์น้อยกว่าวงจรก่อนหน้า เพราะยิ่งสัญญาณเปลี่ยนเร็ว ขาออกยิ่งใหญ่ สัญญาณรบกวนความถี่สูงจึงถูกขยายตามไปด้วย แต่กับคลื่นสามเหลี่ยมมันทำสิ่งที่สวยงาม: ความชันของแต่ละขาคงที่ ขาออกจึงเป็นคลื่นสี่เหลี่ยม

Swap the places so that C is at the input and R in the feedback (slide p. 6). The current through C follows how fast the input voltage changes, which gives \(v_o(t) = -RC\,\dfrac{dv_1(t)}{dt}\).

The slide admits it is less useful than the circuits before it: the faster a signal changes, the bigger the output, so high-frequency noise is amplified too. With a triangle wave, though, it does something neat: each edge has a constant slope, so the output is a square wave.

ขั้นเข้าดิฟเฟอเรนชิเอเตอร์ให้อนุพันธ์เป็นอนันต์ ขาออกในภาพจำลองจึงกระชากชนรางหนึ่งก้าวเวลาแล้วกลับ
A step into the differentiator has an infinite derivative, so the simulated output spikes to the rail for one time step and returns.

  1. Integrator + ±1 V square at 100 Hz with R = 100 kΩ, C = 0.1 µF (RC = 10 ms): a 5 ms half period at 100 V/s gives a ±0.25 V triangle. Raise the frequency to 1 kHz: ±0.025 V (it falls as 1/f). This is a kind of low-pass filter.
  2. Integrator + sine: the output is minus a cosine, 90° behind, of size \(A/\omega RC\). Check at the frequency where \(\omega RC\) = 1: the output equals the input.
  3. Differentiator + step: a spike to the rail for one time step, then back to zero (the charge rushes into C in one step). Real circuits add a resistor in series with C to tame this pulse.

Try this 2 — problems 1–4

  1. Problem 1: while the output ramps down, hover over C: a constant 1 µA, yet a steadily rising voltage: the very definition of a capacitor, \(i = C\,dv/dt\).
  2. Problem 2: at 173 ms the output hits the −13 V rail; hover over the op-amp: \(V_d\) is no longer zero, and R's current no longer enters C (the dots stop).
  3. Problem 4: while the input rises the dots run one way, while it falls the other; the 40 µA magnitude is constant through each half period.
