## รูปแบบของหน้า (เหมือน EE_Web)

กรอบสมการ → ประเด็นสำคัญ → รูปสไลด์ → หมายเหตุสไลด์ (warnbox) → สารบัญ → ส่วนสาธิต A, B, … (ภาพจำลอง + แผงควบคุม + คำอธิบายที่เปลี่ยนตามค่า) → โจทย์ทีละข้อ (โจทย์ ลองตอบก่อน ภาพจำลองที่เปลี่ยนตามขั้น เฉลยทีละขั้นด้วยปุ่ม) → ฝึกเพิ่ม → ลองทำดู
- รูปสไลด์อยู่ในหน้า แตะเพื่อขยาย รูปเดียวกันไม่ซ้ำ
- สมการจัดตรงเครื่องหมาย = และใส่กรอบคำตอบ ภาษาอังกฤษไม่มีอักษรไทย ตัวย่อเขียนเต็มครั้งแรก
- มิเตอร์วัด V/A ในวงจรซ่อนในโจทย์จนกว่าจะเปิดเฉลย (จาก EE_Web)
- กล่องความเห็นท้ายหน้า (shell.js `FEEDBACK`) ยังปิดอยู่: `FEEDBACK.form` ว่าง จนกว่าจะสร้างแบบฟอร์มของวิชานี้ (บนเครื่องตัวเองยังเห็นเป็นตัวอย่าง)

## ไดโอดในตัวแก้วงจร (`circuit.js`, part type `D`)

- `model: 'shockley'` (ค่าเริ่มต้น): สมการ (1.2) `Is`, `n`, `T` (°C) · `vz` ทำให้พังทลายที่ −vz (`ibv` A ที่ −vz) · `zsym: false` วาดสัญลักษณ์ไดโอดธรรมดาแม้มี `vz`
- `'table'`: `curve: [[V, A], …]` จาก 0 V ขึ้นไป (pchip ของ Fritsch–Carlson) และ `Irev` (A) ด้านไบแอสกลับ
- `'ideal'`, `'simple'` (`vk`), `'pwl'` (`vk`, `r`) · `led: true` วาดลูกศรแสงและแสงเรือง (`ledColor`, `ledFull`)
- แก้ด้วย Newton–Raphson ครอบการแก้ MNA เดิม (`solve1`): จำกัดก้าวแบบ SPICE (pnjlim) สำหรับเอกซ์โพเนนเชียล ก้าวละไม่เกิน 0.25 V สำหรับตาราง และหน่วงก้าวของแบบเส้นตรงหลัง 60 รอบ ใช้ได้ทั้งกระแสตรงและการจำลองตามเวลา (กระแสสลับใช้ความชันที่จุดกระแสตรงล่าสุด)
- \(V_T\) ใช้ค่าคงที่ของตำรา k = 1.38e-23, q = 1.6e-19, T_K = 273 + °C → 25.875 mV ที่ 27 °C (Example 1.1)

## ข้อผิดพลาดในสไลด์ที่หน้าเว็บแจ้งไว้

- หน้า 8, 9, 13, 45, 50, 54: สมการหายไปจากไฟล์ PDF (เว้นว่างหลัง "is" / "as shown in Figure" / "In equation form")
